# ALFAWALI project router

Leia `AGENTS.md` e `docs/producao-site/README.md` para orientação geral. Antes de alterar, verifique o estado do Git e preserve mudanças do usuário.

Escolha uma única habilidade sempre que possível:

- Dados, catálogo e perguntas ao Wanderlei: `alfawali-content-intake`.
- Fotos reais autorizadas e galeria: `alfawali-photo-curation`.
- Pesquisa orgânica, SEO técnico/local: `alfawali-seo-local`.
- Oferta, publicidade orgânica e campanhas: `alfawali-marketing-growth`.
- Testes, gate, hosting e rollback: `alfawali-release-qa`.

Não carregue todas as skills para tarefas pequenas. Separe fatos, hipóteses e pendências. Não invente capacidades nem ultrapasse a autorização atual. Publicação, contratação, anúncios e alterações em contas externas exigem pedido explícito para aquela ação. A base é estática: orçamento prepara uma mensagem para a pessoa revisar e enviar no WhatsApp; não há checkout, login, banco ou CRM.

Para cada etapa, reporte resultado, arquivos, verificações, itens bloqueados e próxima ação. Use `docs/producao-site/PROMPT-MESTRE.md` para novo contexto e `briefing-do-tio.md` para coleta.
